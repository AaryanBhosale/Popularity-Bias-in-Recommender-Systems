# Popularity-Bias-in-Recommender-Systems
Temporal benchmark of popularity bias in recommender systems on MovieLens-1M, with user-adaptive popularity-penalty reranking (MF-BPR, Item-kNN, EASE, LightGCN)
## 1. Project Overview
This project benchmarks recommender systems and evaluates methods for reducing popularity bias on the MovieLens 1M dataset, using a chronological 80/10/10 train/validation/test split and full-catalogue ranking.

- **Core models:** Most-Popular, Item-kNN, and Matrix Factorization trained with Bayesian Personalized Ranking (MF-BPR).
- **Debiasing methods:** fixed popularity-penalty reranking and user-adaptive popularity-penalty reranking (hyperparameters selected on validation only).
- **Analyses and extensions:** user-group analysis, ablation, Head/Middle/Tail calibration (KL divergence), Decision Tree explanation, EASE, LightGCN, popularity-weighted MF-BPR, calibrated reranking, and seed-robustness.
- **Metrics:** Recall@10/20, NDCG@10/20, ARP@10, Tail Share@10, Coverage@10, Gini@10.

## 4. Installation

1. Install Python 3.10 or newer (3.13 recommended) from https://www.python.org/downloads/ and make sure it is added to PATH.
2. Open Terminal (macOS/Linux) or Command Prompt/PowerShell (Windows) and go to the folder that contains `Team14.ipynb`.
3. (Recommended) Create and activate a virtual environment.

   **macOS / Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
   **Windows PowerShell**
   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```
4. Install the packages:
   ```bash
   python -m pip install --upgrade pip
   python -m pip install numpy pandas scipy matplotlib scikit-learn torch jupyter ipykernel
   ```
   > PyTorch options differ by platform (CPU vs CUDA). See https://pytorch.org/get-started/locally/. The CPU build is sufficient for this project.
5. Start Jupyter:
   ```bash
   jupyter notebook
   ```
   (or `jupyter lab`).
6. In the browser, open **`Team14.ipynb`**.

*Google Colab alternative:* upload `Team14.ipynb` to Colab and run it there; all required packages are normally preinstalled.

## 5. Step-by-Step Instructions to Run the Code

1. **Open the notebook.** Start Jupyter from the project folder and open `Team14.ipynb`.
2. **Select the kernel.** Choose the Python environment in which the packages from Section 4 were installed.
3. **Run all cells in order, top to bottom.** Use **Run → Run All Cells**, or press `Shift + Enter` on each cell. Do not skip cells: later cells depend on variables created earlier.
4. **Dataset download (automatic).** The data-loading cell downloads MovieLens 1M from GroupLens if `data/ml-1m/ratings.dat` does not exist, then extracts it. Expected printout: `Raw ratings: 1,000,209`.
5. **Preprocessing and split.** Ratings ≥ 4 become positives, iterative 5-core filtering is applied, and a chronological 80/10/10 split is created. Expected printout: `Users: 6,034 | Items: 3,125` and `Train: 459,500 | Validation: 57,438 | Test: 57,438`.
6. **Baselines.** Most-Popular, Item-kNN, and MF-BPR are trained and evaluated on validation and test (MF-BPR prints per-epoch loss).
7. **Debiasing experiments.** Fixed and user-adaptive penalties are tuned on validation (selected: fixed α = 0 / 0.03 / 0 and adaptive range 0–0.1), then final models are refit on train + validation and evaluated on test.
8. **Analysis and figures.** The notebook produces the user-group analysis, ablation, comparison plots, calibration results, and Decision Tree analysis.
9. **Additional experiments.** Later sections run EASE, LightGCN, popularity-weighted MF-BPR, calibrated reranking, and the seed-robustness study. These are slower than the core sections, especially on CPU.
10. **Save.** Use **File → Save Notebook** to keep the outputs.

**Approximate run time:** about 15–45 minutes for the full notebook on a typical laptop CPU (a GPU only speeds up LightGCN). To get a quick check, run only Sections 1–9 (core experiments).

## 8. Troubleshooting
- **Download error:** check your internet connection and rerun the data-loading cell. Otherwise download the ZIP manually from the URL above and extract it so that `data/ml-1m/ratings.dat` exists.
- **`ModuleNotFoundError`:** install the missing package into the same environment that Jupyter uses (`python -m pip install <package>`), then restart the kernel.
- **Slow execution:** MF-BPR, LightGCN, and the extra experiments train iteratively; CPU execution is supported but slower.
- **GPU:** optional; used automatically by LightGCN when PyTorch detects CUDA.
- **Reproducibility:** the primary configuration uses seed `42`. Different hardware or package versions can cause small numerical differences.
